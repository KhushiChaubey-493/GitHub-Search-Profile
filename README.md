# 🔎 GitHub Profile Search

A responsive web application that uses the **GitHub REST API** to search for GitHub users and display relevant profile information.

## 📌 Overview

GitHub Profile Search was created to practice **REST API integration, JavaScript, asynchronous data handling, and dynamic DOM manipulation**.

Users can search for a GitHub account and view information retrieved directly from the GitHub API.

## ✨ Features

* Search for GitHub users
* Retrieve profile information using the GitHub REST API
* Display user profile information
* Display follower count
* Display following count
* Display repository information
* Dynamically render API data
* Responsive interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* GitHub REST API
* DOM Manipulation

## ⚙️ How It Works

1. The user enters a GitHub username.
2. JavaScript sends a request to the GitHub REST API.
3. The API returns the user's profile information.
4. The application processes the response.
5. The user's information is dynamically displayed in the interface.
